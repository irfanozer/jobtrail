# JobTrail

A Java job-search workspace for finding software engineering roles on official employer boards, keeping application history, and explaining matches against verified career facts.

This repository is under active development. The first release focuses on live Greenhouse and Lever collection, searchable jobs, private profile facts, and application tracking. Resume generation and application submission are later milestones.

Personal profiles, resumes, credentials, and local databases are never part of the repository.

## Stack

Java 21, Spring Boot, PostgreSQL, React, and TypeScript. A local H2 mode is available for development without a database service.
